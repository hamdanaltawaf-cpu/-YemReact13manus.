# تحقق معالجة فيديو أقل من 10MB

تم إنشاء فيديو MP4 فعلي مدته ثانيتان بدقة 1280×720 وحجم **36,981 بايت**، وهو أصغر بكثير من حد YemReact البالغ 10MB. مرر الاختبار العينة عبر `processVideoUpload` الفعلية، لا عبر محاكاة.

| المخرج | النتيجة |
|---|---|
| فيديو المعالجة | MP4 بحجم 37,249 بايت |
| ترميز الفيديو | H.264 |
| ترميز الصوت | AAC |
| الدقة | 1280×720 |
| المدة | ثانيتان |
| الصورة المصغرة | JPEG بحجم 7,160 بايت |
| العلامة المائية | ظهرت «يمن رياكت» في أسفل يمين الصورة المصغرة الناتجة |

كما اجتاز اختبار Vitest الخاص بخدمة الفيديو أربعة اختبارات، منها اختبار حد 10MB والمحافظة على 720p وعدم تكبير المصدر الأصغر من 720p.
